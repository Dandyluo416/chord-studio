移調與文字和弦

02整首移調

所有根音、指定低音一起移調，右手轉位與節奏保留。調中心請依原譜指定；不會從和弦自動判斷大小調。建議以黑鍵數量估算，仍可依歌唱音域決定。

03帶入和弦譜

冒號後可寫持續拍數；沒寫則為一小節。支援 C、Cm、C7、Caug、Cadd9、Cdim、C/E 等；6/9 中的斜線保留。加入時會沿用選定格的伴奏。

iPad 使用方式與音型說明

建議用 Safari 開啟本網頁網址，第一次請點播放或琴鍵來啟動聲音。可從 Safari 分享選單加入主畫面。應用程式會快取介面、程式與鋼琴取樣，不需另外下載音色；若「檔案」App 只顯示靜態預覽，請使用網頁網址，或能執行 JavaScript / Web Audio 的 HTML 開啟工具。

和弦譜模式可編排、移調與播放伴奏，也能匯出 JSON 備份。收音練習可辨識音高；伴奏播放按設定速度進行，不會自動跟隨歌聲。BPM 表示四分音符速度；「每拍音數」控制逐音速度。阿貝提低音為三音和弦的低–高–中–高；1–5–10 是根音、五音、升高八度的三音（小和弦為小十度）。這些數字不代表手指編號。
